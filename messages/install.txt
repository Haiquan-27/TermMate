TermMate for Sublime Text
=========================

Thank you for installing TermMate!

This plugin provides agentic coding interface (Claude Code, Codex,
Google Antigravity, OpenCode, and Pi Agent) directly within Sublime Text.

Getting Started:
- Ensure at least one of the command-line tools (`claude`, `codex`, `agy`,
  `opencode`, or `pi`) is installed on your system based on your preference.
- Authenticate the agents via your terminal:
  - Claude Code: Run `claude /login` in your terminal.
  - Codex: Run `codex login` in your terminal.
  - Google Antigravity: Run `agy` in your terminal.
  - OpenCode: TermMate starts/discovers a local `opencode serve --service`
    automatically; if you run the service yourself, set `OPENCODE_SERVER_URL`
    and `OPENCODE_SERVER_PASSWORD` in TermMate's "env" settings.
  - Pi Agent: Run `pi /login` in your terminal.
- Open the command palette and type "TermMate: Start Chat".

Data Privacy:
By default, this plugin does not send your entire workspace to the agents. Only text you type in the chat, files you explicitly @-mention, and tool-driven context are sent to the AI service.

For more information on features and configuration, see https://github.com/flashmodel/termmate#getting-started

For visual guides and walkthroughs, visit https://termmate.app/sublime/
